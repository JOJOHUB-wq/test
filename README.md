# CustomEnchants - Плагин на Кастомные Зачарования

Добро пожаловать в `CustomEnchants`! Этот плагин предоставляет мощную и гибкую систему для создания и управления кастомными зачарованиями на вашем сервере Minecraft. Он разработан с нуля, чтобы быть максимально настраиваемым, позволяя вам изменять каждый аспект зачарований через конфигурационные файлы.

## ✨ Ключевые особенности

- **Полная настройка зачарований**: Управляйте всем через `enchants.yml` — от максимального уровня и редкости до шанса срабатывания и совместимости.
- **Анимированные GUI-меню**: Красивые и плавные меню для отображения зачарований, полностью настраиваемые через `.yml` файлы.
- **Интеграция со столом зачарований**: Игроки могут получать кастомные зачарования стандартным игровым путем.
- **Гибкая система команд**: Команды для открытия меню и выдачи зачарованных книг администраторами.
- **Продуманная логика**: Зачарования, такие как "Бульдозер" и "Лесоруб", имеют защиту от разрушения защищенных территорий и рекурсивных вызовов.

## 🚀 Установка

1.  Скачайте последнюю версию плагина (`CustomEnchants-1.0-SNAPSHOT.jar`) из папки `target/`.
2.  Поместите `.jar` файл в папку `plugins` вашего сервера.
3.  Перезапустите сервер.
4.  После первого запуска в папке `plugins/CustomEnchants/` будут созданы конфигурационные файлы `enchants.yml` и папка `menus/` с файлами меню. Настройте их по своему усмотрению.

## 🔧 Команды и права доступа

| Команда                                        | Описание                                    | Права доступа (`permission`) |
| ---------------------------------------------- | ------------------------------------------- | ---------------------------- |
| `/enchants`                                    | Открывает главное меню кастомных зачарований. | `customenchants.menu` (по умолчанию у всех) |
| `/giveenchant <игрок> <название_чар> [уровень]` | Выдает игроку книгу с кастомным зачарованием. | `customenchants.give`        |

## ⚙️ Настройка `enchants.yml`

Это сердце плагина. Здесь вы можете настроить каждое зачарование.

**Пример структуры для одного зачарования:**

```yaml
enchantments:
  Vampirism:
    # Включено ли зачарование? (true/false)
    enabled: true
    # Имя, которое будет отображаться в описании предмета.
    display_name: "Вампиризм"
    # Максимальный уровень зачарования.
    max_level: 3
    # Редкость. Влияет на шанс получения на столе зачарований.
    # Возможные значения: COMMON, UNCOMMON, RARE, EPIC, LEGENDARY
    rarity: "RARE"
    # Можно ли получить это зачарование на столе зачарований? (true/false)
    enchanting_table_enabled: true
    # Список зачарований, с которыми это несовместимо.
    # Используйте официальные названия Bukkit (напр., "DAMAGE_ALL" для Остроты).
    conflicts_with:
      - "DAMAGE_ALL"
    # Список предметов, на которые можно наложить это зачарование.
    # Используйте официальные названия материалов Bukkit.
    applicable_items:
      - "NETHERITE_SWORD"
      - "DIAMOND_SWORD"
    # Настройки для каждого уровня.
    levels:
      1:
        # Шанс срабатывания эффекта (0.10 = 10%).
        chance: 0.10
        # Количество восстанавливаемого здоровья (в полу-сердцах).
        heal_amount: 1.0
      2:
        chance: 0.15
        heal_amount: 1.0
      3:
        chance: 0.20
        heal_amount: 2.0
```

### Параметры, специфичные для зачарований:

-   **Vampirism**: `chance`, `heal_amount`
-   **Poison**: `chance`, `duration` (в секундах), `amplifier` (0 = Яд I, 1 = Яд II)
-   **Oxidation**: `extra_damage` (дополнительный урон по броне)
-   **Glow**: `chance`, `duration` (в секундах)
-   **Experienced**: `xp_multiplier` (множитель опыта, напр., 1.2 = +20%)
-   **Hunter**: `cooldown_ticks` (задержка в тиках, 20 тиков = 1 секунда), `power` (сила выстрела)
-   **Stupor**: `chance`, `duration` (в секундах), `amplifier`
-   **Sniper**: `bonus_damage_per_block` (бонусный урон за каждый блок дистанции)
-   **Hawk**: `damage_multiplier` (множитель урона при стрельбе в воздухе)
-   **Bulldozer**: `radius` (1 = 3x3, 2 = 5x5)
-   **Lumberjack**: `max_blocks` (максимальное количество срубаемых блоков)
-   **AutoSmelt**: `xp_bonus`, `smelt_map` (карта переплавки)
-   **Dodge**: `dodge_chance_per_level` (шанс уклонения за каждый общий уровень на броне)
-   **Jumper**: `power` (сила двойного прыжка)
-   **Poison-Thorns**: `damage_to_duration_multiplier` (множитель урона в длительность), `max_duration_ticks`, `amplifier`

## 🎨 Настройка меню

Все меню находятся в папке `plugins/CustomEnchants/menus/`. Вы можете редактировать их, изменять предметы, названия, описания и анимации.

-   **`[OPEN] <id_меню>`**: команда для открытия другого меню.
-   **`[CLOSE]`**: команда для закрытия текущего меню.
-   Любая другая строка будет выполнена как команда от имени игрока.
